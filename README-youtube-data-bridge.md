# YouTube Data Bridge

เครื่องมือเว็บแบบ local-first สำหรับอ่าน Google Takeout ของ YouTube และทำเฉพาะงานที่ YouTube รองรับอย่างเป็นทางการ

## ความเป็นส่วนตัว

- ไฟล์ Takeout ถูกอ่านในเบราว์เซอร์ของผู้ใช้เท่านั้น
- ไม่มีการอัปโหลด Watch history, Search history หรือไฟล์ Takeout ไปยังเซิร์ฟเวอร์ของเครื่องมือนี้
- OAuth token อยู่ในหน่วยความจำของหน้าเว็บและใช้เฉพาะ YouTube Data API
- ห้ามนำไฟล์ Takeout หรือไฟล์ JSON ส่วนตัวเข้า Git หรือ Vercel

## ข้อมูลที่รองรับ

- ช่องที่ติดตาม: อ่าน CSV แล้วสมัครเฉพาะช่องที่ยังไม่มีในบัญชีปลายทาง
- เพลงในคลัง YouTube Music: อ่าน `music library songs.csv` แล้วเก็บเป็นเพลย์ลิสต์ส่วนตัว
- เพลย์ลิสต์: อ่าน CSV ในโฟลเดอร์ `playlists` แล้วสร้างเพลย์ลิสต์ส่วนตัวตามชื่อไฟล์
- วิดีโอที่กดชอบ: อ่าน `playlists/likes.json` หรือไฟล์ My Activity ที่เลือกเพิ่ม แล้วกดชอบผ่าน YouTube API
- ประวัติการดู: สร้างเพลย์ลิสต์ส่วนตัวจากวิดีโอที่อ่านได้ แต่ไม่สามารถบันทึกเป็น Watch history ย้อนหลัง
- ประวัติการค้นหา: อ่านและสรุปความสนใจได้ แต่ YouTube ไม่มี API สำหรับเขียนกลับเป็น Search history

เพลงหรือวิดีโอที่ถูกลบ ตั้งค่าจำกัด หรือ API ไม่อนุญาต อาจเพิ่มไม่สำเร็จ เครื่องมือข้ามรายการซ้ำในเพลย์ลิสต์และตรวจช่อง/การกดชอบที่มีอยู่ก่อน

## ใช้กับไฟล์ Takeout

1. เปิดเว็บ แล้วเลือกโฟลเดอร์ `Takeout` ของบัญชีต้นทาง
2. ตรวจสอบจำนวนข้อมูลและสรุปความสนใจที่อ่านได้
3. ตรวจสอบ OAuth Client ID ที่ตั้งค่าไว้สำหรับเว็บนี้
4. กดเชื่อมต่อด้วย Google OAuth และเลือกบัญชีปลายทางของตัวเอง
5. ตรวจข้อมูลที่พบ แล้วใช้ปุ่มย้ายเฉพาะหมวดที่ต้องการ

หาก Likes หรือกิจกรรมไม่อยู่ในโฟลเดอร์ YouTube ให้ส่งออก YouTube จาก Google My Activity เพิ่ม แล้วใช้ปุ่ม “เพิ่มไฟล์ My Activity” เลือกไฟล์ JSON/HTML ที่เกี่ยวข้อง

ผู้ดูแลเว็บต้องตั้ง Authorized JavaScript origin เป็น URL ของเว็บ และเผยแพร่ OAuth consent screen ก่อนเปิดให้ผู้ใช้ทั่วไปเชื่อมต่อ

ไฟล์จะถูกอ่านในเบราว์เซอร์ ไม่ถูกอัปโหลดไปยังเซิร์ฟเวอร์ของเครื่องมือนี้

## เชื่อมบัญชีปลายทาง

แอปใช้เฉพาะ scope `https://www.googleapis.com/auth/youtube.force-ssl` สำหรับ YouTube Data API v3 เท่านั้น ไม่ขอสิทธิ์ Gmail, Drive หรือบริการอื่น

## โควตาและขอบเขต

- การกดชอบวิดีโอใช้ 50 quota units ต่อวิดีโอที่ต้องกดชอบตาม YouTube Data API; โควตารายวันของแต่ละโปรเจกต์อาจจำกัดจำนวนที่ย้ายได้
- YouTube ไม่มี API ทางการสำหรับเขียน Watch history หรือ Search history ย้อนหลังเข้าไปในบัญชีใหม่โดยตรง เครื่องมือนี้จึงสร้างได้เพียง private playlist จากวิดีโอเดิม
- ไม่ย้ายคำแนะนำ/โปรไฟล์ความสนใจภายในของ YouTube, ความคืบหน้าการดู, ประวัติการค้นหาย้อนหลัง, คอมเมนต์ หรือข้อมูลบริการ Google อื่น
