# YouTube Data Bridge

เครื่องมือเว็บแบบ local-first สำหรับอ่าน Google Takeout ของ YouTube และทำเฉพาะงานที่ YouTube รองรับอย่างเป็นทางการ

## ความเป็นส่วนตัว

- ไฟล์ Takeout ถูกอ่านในเบราว์เซอร์ของผู้ใช้เท่านั้น
- ไม่มีการอัปโหลด Watch history, Search history หรือไฟล์ Takeout ไปยังเซิร์ฟเวอร์ของเครื่องมือนี้
- OAuth token อยู่ในหน่วยความจำของหน้าเว็บและใช้เฉพาะ YouTube Data API
- ห้ามนำไฟล์ Takeout หรือไฟล์ JSON ส่วนตัวเข้า Git หรือ Vercel

## ใช้กับไฟล์ Takeout

1. เปิดเว็บ แล้วเลือกโฟลเดอร์ `Takeout` ของบัญชีต้นทาง
2. ตรวจสอบจำนวนข้อมูลและสรุปความสนใจที่อ่านได้
3. ตรวจสอบ OAuth Client ID ที่ตั้งค่าไว้สำหรับเว็บนี้
4. กดเชื่อมต่อด้วย Google OAuth และเลือกบัญชีปลายทางของตัวเอง
5. ใช้ปุ่มสมัครช่องเดิมหรือสร้างเพลย์ลิสต์ส่วนตัวหลังตรวจสอบรายการแล้ว

ผู้ดูแลเว็บต้องตั้ง Authorized JavaScript origin เป็น URL ของเว็บ และเผยแพร่ OAuth consent screen ก่อนเปิดให้ผู้ใช้ทั่วไปเชื่อมต่อ

ไฟล์จะถูกอ่านในเบราว์เซอร์ ไม่ถูกอัปโหลดไปยังเซิร์ฟเวอร์ของเครื่องมือนี้

## เชื่อมบัญชีปลายทาง

แอปใช้เฉพาะ scope `https://www.googleapis.com/auth/youtube.force-ssl` สำหรับ YouTube Data API v3 เท่านั้น ไม่ขอสิทธิ์ Gmail, Drive หรือบริการอื่น

## ขอบเขตที่ตั้งใจไว้

- YouTube ไม่มี API ทางการสำหรับเขียน Watch history หรือ Search history ย้อนหลังเข้าไปในบัญชีใหม่โดยตรง เครื่องมือนี้จึงสร้างได้เพียง private playlist จากวิดีโอเดิม และสมัครช่องเดิมหลังผู้ใช้ยืนยัน
