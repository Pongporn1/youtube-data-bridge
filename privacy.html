YouTube Data Bridge อ่านไฟล์ Google Takeout ภายในเบราว์เซอร์ของผู้ใช้ และไม่อัปโหลดไฟล์ Takeout ไปยังเซิร์ฟเวอร์ของเครื่องมือนี้

เมื่อผู้ใช้เลือกทำรายการ ข้อมูลที่จำเป็น เช่น รหัสวิดีโอ รหัสช่อง และชื่อเพลย์ลิสต์ จะถูกส่งตรงไปยัง YouTube Data API เพื่อสร้างเพลย์ลิสต์ กดชอบวิดีโอ หรือสมัครช่องตามที่ผู้ใช้ยืนยัน เครื่องมือไม่ขอสิทธิ์ Gmail หรือ Google Drive และไม่เก็บรหัสผ่าน

OAuth access token ใช้ชั่วคราวในหน่วยความจำของหน้าเว็บและจะหายเมื่อปิดหรือโหลดหน้าใหม่ ประวัติการดู/ค้นหาที่นำเข้าเพื่อสรุปจะอยู่ในเบราว์เซอร์ เว้นแต่ผู้ใช้สั่งสร้างเพลย์ลิสต์จากรายการดู
