ปลายทาง

เลือกบัญชี Google ปลายทางของคุณในหน้าต่าง OAuth

ตั้งค่าไว้สำหรับเว็บนี้แล้ว ผู้ใช้แต่ละคนจะเลือกบัญชีปลายทางของตัวเองผ่าน Google OAuth · Authorized JavaScript origin:
ยังไม่ได้เชื่อมต่อบัญชีปลายทาง

สมัครช่องเดิม รองรับโดย API

ใช้รายชื่อช่องจาก CSV เพื่อสมัครในบัญชีปลายทาง ไม่แตะประวัติการดู

เก็บวิดีโอเดิมเป็นเพลย์ลิสต์ ไม่ใช่ history

สร้างเพลย์ลิสต์ส่วนตัวในปลายทางเพื่อเปิดดูรายการเดิมได้ YouTube จะไม่บันทึกเป็นประวัติย้อนหลัง

ทำไม่ได้โดย API: เขียน Watch history หรือ Search history ย้อนหลังเข้าไปในบัญชีใหม่โดยตรง ดังนั้นปุ่มด้านบนจะไม่แอบทำสิ่งนั้น
ข้อมูล Takeout อยู่ในเครื่อง · OAuth token อยู่ในหน่วยความจำของหน้านี้ข้อจำกัดทางการของ YouTube · YouTube Data API
